# Project Overview
This Excel project analyzes taco delivery data to understand order patterns, delivery performance, and revenue distribution. The project demonstrates data cleaning, transformation, KPI creation, interactive filters (slicers), and visualizations using Microsoft Excel.


# Data Set
-----------------------------------------------------
columns       |	Description
Order ID	    |Unique identifier for each order
Restaurant    |Name	Name of the restaurant
Location	    |Delivery location
Order Time	  |Time when the order was placed
Delivery Time	|Time when the order was delivered
